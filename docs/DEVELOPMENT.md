### v0.1.1 通知中心 ✅ 已完成
- **核心功能**：聚合 GitHub/Gitea/GitLab 未读通知，支持桌面弹窗提醒
- **子任务预估**：5-6 个（通知数据获取、通知聚合逻辑、TUI 通知中心、桌面通知集成、通知状态持久化）

- **版本类型**：minor
- **版本号**：v0.1.1

- **核心功能**：仓库发现 + 状态仪表盘 + 批量操作 + GitHub 认证 + 配置持久化 + Submodule 状态 + 仓库分组
- **子任务预估**：8 个（项目骨架、配置管理、Git 操作层、状态仪表盘、批量操作、GitHub 认证、Submodule 支持、仓库分组）
- **依赖**：无（首个里程碑）
- **版本类型**：minor
- **版本号**：v0.1.0
